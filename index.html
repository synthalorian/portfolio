01 / about

Built close to the metal

I’m synth (synthalorian on GitHub), a developer in Florida. The work runs from the engine room to the desktop: a hot-reloading game engine in Odin, a JUCE synthesizer with VST3 and CLAP builds, a Rust AI coding harness with persistent memory, mesh-networking tools for Reticulum, and offline-first Flutter apps for Android and iOS. Much of it is local-first by design: your data stays on your machine.

Off the keyboard I play guitar on a praise team, which is where projects like Setlist and Open Praise come from.

Blackshield Company is my solo studio, home to my digital forensics and security tooling, an AI platform and a few theme packs.

Six projects to start with

The ones I’d show you first. Every one is open source under Apache-2.0.

/01 · AI developer toolingRust

OpenShield

An AI coding harness for the terminal, in Rust.

  • Works with any OpenAI-compatible provider, including local servers like Ollama and llama.cpp.
  • Persistent SQLite-backed sessions with keyword and semantic search.
  • Autonomous agent mode: plans, executes, verifies, retries. You approve the plan.
  • Rust
  • TUI
  • LLM
  • SQLite

Latest release v1.2.2 · Apache-2.0

GitHubReleasesDesktop appAndroid app
/02 · Game techOdin

VoidEngine

A lightweight game engine with hot reload, in Odin and SDL2.

  • Reloads game logic as a shared library without restarting the engine.
  • ECS, 2D physics and collision, audio, tilemaps, particles, fixed-timestep loop.
  • A 3D sprite and mesh renderer with OpenGL 3.3 and Vulkan backends: HDR point lights, bloom, OBJ loading.
  • Odin
  • SDL2
  • ECS
  • Vulkan

Version v0.6.0 (per README, no GitHub release yet) · Apache-2.0

GitHubVoid Mercs demo
/03 · Audio softwareC++

Open Synth

An open-source synthesizer: standalone app plus VST3 and CLAP.

  • JUCE 8 and C++20 engine, with an AU build on macOS as well.
  • Wavetable, FM and physical-modeling oscillators, a sample ROMpler, and a 4-slot multi-effects chain with 22 processor types.
  • 16-part multitimbral, with 5,600 presets across 20+ categories.
  • C++
  • JUCE
  • VST3
  • CLAP

Latest release v2.3.0 · Apache-2.0

GitHubReleases
/04 · Security and API toolingRust

wireclaw

A local HTTP/HTTPS proxy that watches your API traffic.

  • Captures every request and response into SQLite, organized by session.
  • Real-time web dashboard and a terminal UI that works over SSH.
  • Replay, search and structural diff, plus export to OpenAPI 3.0, HAR, curl and Postman.
  • Rust
  • Proxy
  • TUI
  • OpenAPI

Latest release v1.1.0 · Apache-2.0

GitHubReleases

Open Bible

An offline Bible study app for Android and iOS, in Flutter.

  • Text-to-speech and structured reading plans, with no data connection needed.

04 / modding

Skyrim mods

Fifteen mods for The Elder Scrolls V: Skyrim Special Edition, released as three waves that are designed to run together.

Every mod stands on its own: separate records, prefixes and scripts, and no vanilla record edits. Blackshield Codex is the optional bridge that makes the first five notice each other.

All mods on Nexus →
Game
Skyrim Special Edition / Anniversary Edition 1.6 (1.5.97 works too)
Plugins
15, all ESL-flagged, so none take a full load-order slot
Requires
Base game only. No SKSE, SkyUI, DLC or Creation Club. The Codex needs the first five.
Status
Early beta, not yet playtested in game. Bug reports welcome on Nexus or GitHub.
